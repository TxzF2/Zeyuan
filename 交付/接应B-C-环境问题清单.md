## 一、高频问题速查（先自查，能省 20 分钟）

| # | 现象 | 最可能原因 | 处理（发给节点照做） |
|---|---|---|---|
| 1 | 安装器双击没反应 | 被 Defender/杀软拦截；未解压直接双击压缩包内 exe | 右键 → 属性 → **解除锁定**；解压到本地目录再运行 `zeyuan-installer.exe` |
| 2 | 装完打开 DSH，**设置里没有泽元面板** | ① 未重启 DSH ② profile 未接线 ③ 插件目录缺 | 先重启；再查 `%LOCALAPPDATA%\zeyuan\app\plugins` 是否有 8 个 `zeyuan-*`；再看 `~/.dsh/profiles/desktop/package.json` 的 `dsh.profile.bundles` 是否含 `zeyuan-*` |
| 3 | 面板在，但显示"无法连接服务" | 插件未加载（host 半报错） | 看 DSH 控制台日志里 `[zeyuan-*]` 前缀报错；常见是缺 `license` 或 `node_modules` 链接断 |
| 4 | 协议授权页签不了 / 提示 E-601 | 未签协议或 license 缺失 | 设置 → 泽元 · 协议授权 → 签署；若报"license 文件缺失"，检查 `%LOCALAPPDATA%\zeyuan\license.json` 与 `license.key` |
| 5 | `git clone` / 下载分卷超时 | **国内网络对 GitHub 不稳定（已实测：raw 200 但截断）** | 不用 GitHub 直连；走网盘整包（下载页"网盘备用下载"）；或等 Gitee 镜像 |
| 6 | 合并分卷后哈希不对 | 分卷没下全（小于 25MB）或顺序错 | 对照 `PARTS.txt` 逐个核大小；用同目录 `merge.cmd` 合并，不要手动改名 |
| 7 | 端口 19387 被占用 | 旧 DSH 进程没退干净 | `Get-Process 'DeepSeek Harness'` 全杀 → 重开 |
| 8 | 杀软报毒（安装器/插件） | 未签名便携包常见误报 | 加白名单；或用 `SHA256校验.txt` 证明包完整性 |
| 9 | Node/Git 缺失（要跑脚本时） | 便携版**无需** Node/Git 即可安装运行 | 只有"下载分卷/迁移"这类脚本才需要；优先用网盘整包 |
| 10 | 装好但任务/社区数据是空的 | 正常（新环境无数据） | 不是故障；老数据需跑 `migrate-zeyuan.mjs`（旧版升级场景） |

# 泽元 v0.4.0 升级说明（技术 id 改名版）

> 适用：从 v0.3.0（包名 `dsh-training-*`）升级到 v0.4.0（包名 `zeyuan-*`）。

## 一、这次改了什么

| 项 | v0.3.0 | v0.4.0 |
|---|---|---|
| 插件包名 | `dsh-training-protocol` 等 7 个 | **`zeyuan-protocol` 等 7 个** |
| 事件命名空间 | `dsh-training:<board>:<action>` | **`zeyuan:<board>:<action>`** |
| 状态目录 | `%LOCALAPPDATA%\dsh-training` | **`%LOCALAPPDATA%\zeyuan`** |
| 安装器 | `dsh-training-installer.exe` | `zeyuan-installer.exe` |
| 产品名 | 培训班 | **泽元** |

## 二、全新安装（没装过旧版）

1. 解压 `zeyuan-portable-v0.4.0-20261025-x64.zip`；
2. 双击 `zeyuan-installer.exe`，按向导安装；
3. 启动后进入 **设置 → 泽元 · 协议授权** 签署协议；
4. 其余面板：任务接发 / 工作台 / 社区 / 协作分组 / 泽元中转站。

## 三、从 v0.3.0 升级（有旧数据）

```powershell
# 1) 先迁移数据（dry-run 看计划，确认后加 --apply）
node migrate-zeyuan.mjs
node migrate-zeyuan.mjs --apply

# 2) 再安装 v0.4.0（zeyuan-installer.exe）
# 3) 重启 DSH 桌面端
```

迁移脚本会做四件事：状态目录复制到 `zeyuan`、事件日志改名并升级为五键信封、挂载记录改名、profile 接线改名（带备份）。
**旧目录 `dsh-training` 不会被删除**，可随时回滚。

## 四、回滚

```powershell
Copy-Item "$env:USERPROFILE\.dsh\profiles\desktop\package.json.bak-*" "$env:USERPROFILE\.dsh\profiles\desktop\package.json"
Remove-Item "$env:LOCALAPPDATA\zeyuan" -Recurse -Force
# 再重装 v0.3.0（已停产，仅应急）
```

## 五、旧包状态

**v0.3.0（泽元-便携版-v0.3.0-20261024）已停产，请使用 v0.4.0。**
旧包仍是旧命名空间，与 v0.4.0 数据**不互通**；继续使用的用户不会收到新功能。

## 六、兼容期说明

v0.4.0 的代码在 `%LOCALAPPDATA%\zeyuan` 不存在时会**只读回退**到 `%LOCALAPPDATA%\dsh-training`，
方便尚未迁移的用户先升级不丢数据；但写入永远走新目录。建议仍按第三节执行迁移。

## 三、协议授权过场 · 8 镜分镜（30 fps，总时长 13.0 s）

| 镜 | 时间 | 画面内容 | 相机 / 技术 | 音效点 |
|---|---|---|---|---|
| 1 | 0.0–1.2s | 黑场，星尘从画面四角向中心汇聚 | 静止广角 + 粒子系统（自外向内） | 低频铺底渐入 |
| 2 | 1.2–3.0s | **粒子光线逐段描出镰刀锤子轮廓**（先锤柄→锤头→镰刃） | 粒子沿 Curve 生长；曲线用 4 段贝塞尔拼弧 | 「叮」三声，每段一声 |
| 3 | 3.0–4.2s | 标志整体旋转 90°，红光从锤头扫向镰刃 | 标志自转 + 自发光遮罩动画（沿 U 向渐变） | 金属摩擦声 |
| 4 | 4.2–6.0s | 星轨浮现，长征姬由**剪影 → 实体**（先轮廓光后填色） | 剪影：纯黑材质 + 边缘光；透明度 0→1 + Fresnel 增强 | 星轨嗡鸣 |
| 5 | 6.0–8.0s | 她抬眼看镜头，银发与衣摆定住 | 85mm 特写，浅景深（f/2.0） | 呼吸声 |
| 6 | 8.0–10.5s | 宣读协议：粒子在身侧逐字成句 | 粒子字幕沿弧线排布；口型 8 组关键帧 | 朗读人声 |
| 7 | 10.5–12.0s | 掌心转向受权者，红光扩散，标志定格胸前 | 中景 + bloom（辉光阈值 0.8） | 授权成功音 |
| 8 | 12.0–13.0s | 星轨合拢收束，画面转黑，浮出「LV1 已授权」 | 淡出 + UI 文字层 | 收束尾音 |

**实现要点（给阶段三）**

1. 粒子描边用 **Curve + 沿曲线生长的粒子**，不要用流体；每段给独立时间偏移才能"逐段点亮"。
2. 剪影→实体：同一套网格上叠两个材质槽，用 `Object Index` 遮罩做过渡，避免复制模型。
3. 粒子字幕建议**在引擎侧做**（Unity/UE 或 WebGL），Blender 里只出参考动画，不追最终效果。
4. 总时长控制在 13 s 内：这是"每次进主玩法都要看一眼"的过场，超过 15 s 会被玩家点跳过。

## 六、被 dsh-training-protocol 插件调用的方式

插件（`plugins/dsh-training-protocol/src/agents.config.ts`）里长征姬目前是：

```ts
{ name: '长征姬', source: 'todo:changzhengji', role: 'reviewer', enabled: false }
```

**接入路径（阶段三落地）**：

1. 把 `out/changzhengji.blend` / `out/txzf.fbx` 复制到安装包的 `characters/<id>/` 板块目录；
2. 把 `agents.config.ts` 的 `source` 从 `todo:` 改为板块资源 id（如 `board:character-changzhengji`）；
3. 协议授权过场由 `dsh-training-protocol` 在 **LV0→LV1 授权成功** 时触发（`tryGrant` 返回 true 后播放 13 s 过场）；
4. 过场期间协议页禁止跳过，播放完才写入 LV1 授权态。

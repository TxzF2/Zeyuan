## 2. 下载与核对（1 分钟）

### 2.1 文件名长什么样

官方安装包文件名一定是这个格式：

```
dsh-training-portable-v0.1.0-20261022-x64.zip    ← 便携版（推荐新手）
dsh-training-setup-v0.1.0-20261022-x64.exe       ← 安装版
```

看三处就能判断是不是正版：
1. 开头必须是 `dsh-training-`；
2. 中间有 `v0.1.0`（**版本号**）和 `20261022`（**日期**）；
3. 结尾是 `-x64.zip` 或 `-x64.exe`。

### 2.2 对一下哈希（可选，但建议）

下载页会给出一个「哈希值前 8 位」，例如 `a1b2c3d4`。核对办法：

1. 在文件上**右键 → 属性 → 文件哈希**（Win11 自带）；
2. 看 SHA256 开头是不是那 8 位。

对不上 = 文件下载不完整或被改过，**删掉重下**。

## 3. 双击之后会发生什么

### 3.1 可能先弹一个蓝色窗口

「**Windows 已保护你的电脑**」——这是 Windows 对新程序的默认拦截，不是你电脑中毒。

处理：点「**更多信息**」→ 点「**仍要运行**」。

【截图位 2：SmartScreen 提示，标注两个按钮】

### 3.2 然后出现安装向导

一个深色、带星点的窗口，标题是「**DSH Agent 培训班 · 安装向导**」。
左边/上方有 5 步：欢迎 → 运行环境 → 板块选择 → 安装 → 完成。

---

## 4. 向导五步（跟着点就行）

### 第 1 步 · 欢迎

- 默认装到你的用户目录（**不需要管理员密码**）；
- 想换位置点「浏览」。建议路径里**不要有中文和空格**，例如 `D:\dsh-training`；
- 点「下一步」。

【截图位 3：欢迎页 + 路径选择】

### 第 2 步 · 运行环境检测

向导自动检测你电脑上有没有 Node 运行时（程序运行需要它，最低 **22.19.0**）。

| 你看到的 | 意思 | 你要做的 |
|---|---|---|
| ✅ 绿色「Node 24.x 可用」 | 正常 | 直接「下一步」 |
| ⚠️ 黄色「未检测到 Node 运行时」 | 电脑里没有 | 点「打开下载页」，装官方 Node（一直点下一步即可），回来点「我已安装，重新检测」 |
| ⚠️ 黄色「版本过低」 | 版本太老 | 同上，升级 Node；或改用便携版（便携版自带运行时，不需要装 Node） |

> **重要承诺**：安装包**不会**偷偷帮你装任何系统组件。缺什么，它只提示，装不装由你决定。

【截图位 4：环境检测结果页（正常态 + 缺失态两张）】

### 第 3 步 · 板块选择（可选装）

这里决定你要装哪些"板块"。像手机装 App 时选组件一样：

| 板块 | 建议 |
|---|---|
| **核心板块 · DSH 运行时 + 协议插件** | 必装，灰掉不能取消 |
| 角色板块 · 星辰（TxzF） | 默认勾上，建议保留 |
| 角色板块 · 长征姬 | 默认勾上，建议保留 |
| 角色板块 · 星辰主题色板 | 默认勾上，建议保留 |
| 功能预览 · 任务接发 / 工作台 / 社区 / 控制面板 / 协作分组 | 默认不勾。**现在装上也只有空占位页**，等阶段三再勾 |

不用担心选择困难：装完之后可以在**控制面板**里随时增删板块。

【截图位 5：板块勾选页】

### 第 4 步 · 安装

点「开始安装」，进度条会走。它会做四件事：

1. 把文件先解到一个临时目录（**不碰你已有的东西**）；
2. 全部校验通过后，才整体替换到位；
3. 中途任何一步失败，**自动回滚**，你原来的版本不受影响；
4. 最后生成一份"装机清单"，卸载时按它精确删除。

如果这里失败了 → 跳到 **第 5 节**。

【截图位 6：安装进度条】

### 第 5 步 · 完成 → LV0 协议页

点「完成」，程序会自动启动，直接停在 **LV0 协议页**。

**LV0 是什么意思？**

| 等级 | 你能做什么 |
|---|---|
| **LV0 · 未授权** | 浏览课程目录、看公开讲义 |
| **LV1 · 已授权** | 解锁实训场、随堂演练、星辰/长征姬的引导式陪练 |

要进 LV1，需要读一遍《培训班协议》并签署——由**星辰（TxzF）**或**长征姬**为你签发授权。
没签署之前，程序不会让你进实训场，这是**故意的**，防止有人跳过协议。

## 5. 安装失败了怎么办（别慌，都能救）

向导会给你一句中文说明 + 一个错误码 + 至少一个按钮。

**通用三步**：
1. 看中文说明，按它说的做（比如"关掉正在运行的程序"）；
2. 点「**重试**」——九成的临时问题（网络、文件被占用）一次重试就好；
3. 还不行，点「**查看日志**」，把日志发给培训助手。

常见错误码对照（只挑最常遇的）：

| 错误码 | 人话解释 | 你可以做什么 |
|---|---|---|
| E-101 | 电脑上没有 Node 运行时 | 点「打开下载页」装 Node，回来点「重新检测」；或换便携版 |
| E-102 | Node 版本太低 | 同上，升级 Node |
| E-201 | 这个文件夹没有写入权限 | 换个目录（推荐用户目录），或换便携版 |
| E-203 | 有文件正被占用 | 关掉培训程序/浏览器后再点重试 |
| E-204 | 下载板块包失败 | 检查网络后点重试 |
| E-205 | 文件不完整或被改过 | 重新下载（文件可能损坏） |

**万一装到一半卡死**：直接关掉向导，你的旧版本还在（安装器不会先删旧的）。
再重新双击安装包即可。

## 6. 卸载与回滚

- **卸载**：设置 → 应用 → 找到「DSH Agent 培训班」→ 卸载。
  便携版直接删除整个文件夹即可（它不写注册表）。
- **回滚到上一版本**：向导的出错页有「回滚到上一版本」按钮；已装状态下也会自动保留上一版备份，重启成功后自动清理。
- **想彻底清干净**：卸载后检查 `%USERPROFILE%\.dsh\plugin-sources\dsh-training` 是否还在（这里有你的学习进度数据，删之前先备份）。

## 7. 常见问题（FAQ）

**Q1：杀毒软件报警了怎么办？**
未签名的程序可能被误报。先核对第 2.2 节的哈希；确认一致后，在杀软里加白名单。若仍不放心，把文件哈希发给培训助手核对。

**Q2：装完双击没反应？**
可能被安全软件拦了。查看杀软的"拦截记录"，恢复后重试；或重启电脑再试。

**Q3：需要管理员密码吗？**
不需要。装到你的用户目录即可。只有选择装到 `C:\Program Files` 时才需要。

**Q4：以后升级会不会丢我的学习进度？**
不会。进度存在用户目录的数据里，升级只替换程序文件。升级前向导会自动备份上一版。

**Q5：公司电脑不让装怎么办？**
用便携版：解压到 U 盘或桌面，双击即用，不写注册表、不需要权限。

**Q6：为什么有些板块装上什么都没有？**
功能预览板块目前是**占位**，阶段三才填充真实功能。它们不装也不影响你学习。

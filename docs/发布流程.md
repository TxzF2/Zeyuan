## 1. 架构（门面 → Release → 本机向导）

```
https://<你的GitHub>.github.io/zeyuan   （docs/download.html，Pages）
   ↓ 点击下载
GitHub Releases（tag v0.4.0：zip + SHA256 + 升级说明）
   ↓ 用户下载
zeyuan-installer.exe 本机向导（已有）
```

一库两用：这个仓库既是**发布仓库**，也是三节点联邦同步通道；网址印在海报上一次即可长期有效。

## 2. 一条命令发版

```powershell
# 0) 先出包
node packaging/scripts/build.mjs --stage 2

# 1) 只看计划（dry-run）
node scripts/release.mjs

# 2) 生成下载页 + 本地打 tag
node scripts/release.mjs --apply

# 3) 推送到 GitHub
node scripts/release.mjs --apply --push

# 4) 创建 Release 并上传资产（gh 已登录）
node scripts/release.mjs --apply --publish
```

| 参数 | 作用 |
|---|---|
| `--page-only` | 只重新生成 `docs/download.html` |
| `--apply` | 校验产物 + 生成下载页 + `git tag -a v<版本>` |
| `--push` | `git push origin main` + 推送 tag |
| `--publish` | `gh release create` 上传 zip / SHA256 校验文件 / 升级说明 |
| `--repo owner/repo` | 覆盖仓库（默认取 `git remote origin`，无则占位符） |

## 3. 下载页（`docs/download.html`）

由脚本生成，包含：

- 最新版本号 / 发布日期 / 大小 / 平台
- **下载直链**：`https://github.com/<repo>/releases/latest/download/<zip>`
- **SHA256 前 8 位**（醒目）+ 完整哈希 + `Get-FileHash` 核对命令
- 历史版本归档链接（`/releases`）
- 安装步骤（含 `zeyuan-installer.exe` 与签约入口）
- 国内镜像 **TODO** 占位

当前生成结果：版本 **v0.4.0**、日期 **20261025**、哈希前 8 位 **32590CB9**。

## 4. GitHub Pages 开启（一次性）

2. Source 选 `Deploy from a branch` → 分支 `main`、目录 `/docs`；
3. 访问 `https://<owner>.github.io/zeyuan/download.html`。

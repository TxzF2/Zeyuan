### D-002 · 安装目录「用户自选」功能冻结

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-22 |
| 决策人 | 项目负责人 |
| 状态 | **已冻结**，阶段三做安装器时再实现 |

**背景**：阶段二第 2 步实现安装线时确定默认安装目录。

**决策**：

1. 默认安装目录固定为 **`%LOCALAPPDATA%\dsh-training`**（免管理员、无中文路径、卸载干净）；
2. **「用户自选安装目录」功能冻结**，本阶段向导不提供路径选择；
3. staging 固定为 `<target>\.staging`，与目标目录**同盘同卷**，保证原子替换走 `rename` 而非跨盘复制；
4. 待阶段三做安装器 exe 时，再一并实现目录选择与「跨盘安装」的降级策略（跨盘只能复制，需额外做失败清理）。

**理由**：目录选择会把同盘假设打破一半，先冻结可以让安装线尽快跑通 A2（失败可回滚）。

### D-003 · License 密钥管理升级（本地对称密钥 → 公钥 + 远程签发）

| 项 | 内容 |
|---|---|
| 日期 | 2026-10-23 |
| 决策人 | 项目负责人 |
| 状态 | **已知限制，暂按本地 HMAC 上线** |

**现状**：`license.key` 与 `license.json` 都在本机用户目录，HMAC-SHA256 对称验签。
防篡改有效，**防伪造无效**——拿到本机文件的人可自行签发。

**升级触发条件**（任一）：
1. 授权开始与"权益"挂钩（付费班、证书、外部认可）；
2. 需要向第三方证明凭据由机构签发；
3. 出现"学员自签 License 绕过限制"的实例。

**升级方案**：Ed25519 密钥对（私钥只在签发端） + 签发服务（HTTPS） + 客户端内置公钥验签；
密钥存储改走 Windows DPAPI / 系统凭据库，禁止明文落盘。

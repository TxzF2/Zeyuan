### D-001 · 放弃 dsh-open-in-vscode，改用「VS Code 直接打开目录」

| 项 | 内容 |
|---|---|
| 日期 | 2026-11-03 |
| 决策人 | 项目负责人 |
| 状态 | **已关闭**，不再探测 |

**背景**：原计划验证 `dsh-open-in-vscode` 集成可用。实测结论：

- 本机未安装 VS Code（`code` 不在 PATH，4 条常见安装路径均无 `Code.exe`）；
- `dsh-open-in-vscode` 在 npm 上**已于 2026-08-16T06:37:22Z 全量下架**（原版本 0.2.0），
  官方源无可用版本；
- 当前 `desktop` profile 也未安装该插件。

**决策**：

1. **不自研**、**不寻找第三方镜像源**；
2. 现阶段用最原始的方式：**用 VS Code 直接打开项目目录**
   （`C:\Users\29496\.dsh\plugin-sources\dsh-training`）；
3. 该探测任务关闭，`scripts/probe-vscode-integration.mjs` 保留但**不再执行**，
   作为历史证据存档。

**未来立项条件（触发再议）**：进入「板块化工作台」阶段，且确需在 DSH 界面内嵌编辑器
（例如左侧文件树 + 内嵌编辑区 + 保存回写）时，再单独立项评估。届时优先考虑：

- 自研轻量文件面板板块（只做「打开目录 / 读取 / 写回」，不追求完整 IDE 能力）；
- 或接入已有 LSP/编辑器组件，而非修补已下架的插件。
